# Changelog

All notable changes to this repository are documented here. Format loosely follows [Keep a Changelog](https://keepachangelog.com/).

Entries are grouped by date. Each game keeps its own rules-version folder (e.g. `warhammer40k/v11`, `killteam/v3`) — when a ruleset changes enough to need its own snapshot, a new version folder is added rather than overwriting the old one.
